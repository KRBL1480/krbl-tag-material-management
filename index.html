3. Total Calculation Summary

MaterialTotal ReceivedReceived Tag CapacityTotal IssuedIssued Tag CapacityBalance QuantityBalance Tag Capacity
Calculation basis: 1 White Roll pack = 27 PCS; 1 Black Ribbon pack = 10 PCS. Then 1 White Roll PCS = 800 finished tags. Black Ribbon PCS is tracked separately at 4,000 tags of ribbon capacity, and is NOT added to finished tag totals. Balance is calculated as received PCS minus issued PCS for each material. Complete tag calculation: each finished tag uses 1 white tag + black-ribbon printing. So finished tags possible = MIN(White Roll PCS × 800, Black Ribbon PCS × 4,000). White Roll and Black Ribbon received, issued, and balance tag capacities are displayed separately; they are not added together.

6. Data Backup & Recovery

Protect your records: Download a full backup regularly and keep it in your office folder or OneDrive/shared drive.

Send / Export Options: Use Export Issue History CSV or Export All Records CSV for Excel, Print Report to save as PDF, Download Shareable HTML Report to send a readable report file, and Download Full Backup (JSON) to transfer/restore all records. CSV and HTML reports are for sharing; JSON is the full data backup.
Important: Entries auto-save in this browser and remain after closing/reopening the file on the same device. However, browser data can be lost if site data is cleared or the computer changes. Keep JSON backups. This standalone HTML does not sync between users/devices and is not connected to KRBL SAP/server.
